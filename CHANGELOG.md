# Changelog

## 0.1.0

Whodunit investigates local failures using code, relevant changes and available agent context. It produces a concise RCA with cited evidence and an optional interactive graph.

Codex inline reports now save automatically in the current chat's permitted visualization folder. This fixes `Invalid visualization read request` when an agent saved a valid card in a worklog or repository folder. Terminal reports continue to save as standalone HTML.

Includes project-local installation for Codex, Claude Code and OpenCode, with preservation of edited skill files.
